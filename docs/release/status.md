## Known limitations (facts)

1. Fixture intelligence only produces content for the supported scenarios and for text/Markdown/CSV inputs. The proposal wording is templated; the client, fee, dates and report numbers come from the supplied sources.
2. Evidence is shown as references to internal source ids, without verbatim quotes (QA A5).
3. An attachment with no usable facts does not stop a proposal that the email body already supports (QA I1); no injected text reaches the outputs.
4. QA A4: the engagement date is printed as `October 26, 2026 (4 calendar weeks)`; the older QA test expected a different date format.
5. Digest notification text (stub) states only a count; the report DOCX chart table shows unformatted `12000`/`15000`.
6. Only page 1 / slide 1 were visually rendered (macOS Quick Look). Word/PowerPoint rendering was not run.
7. The task page pauses its automatic refresh while the browser tab is hidden (by design). In one rehearsal the page stayed on "Queued" while hidden although the task was ready; whether it resumes by itself when the tab is visible again was not established. Reloading the page always shows the stored state.
8. The SpaceXAI UI is Darren's uncommitted work, snapshotted into this branch (`664cc98`). The branch is **not pushed**.
9. One engine fix set (DEF-2/3/4/6) was written by Darren in Joanne's package: review or replace.

Run on the candidate with synthetic fixtures. Commands from a clean checkout:

```bash
pnpm install && pnpm setup:local            # prints where the login password is (the .env file); never show it
pnpm db:migrate && pnpm db:seed && pnpm check:ready
pnpm dev                                    # web :3000, api :4000 (set API_PORT and API_ORIGIN together if 4000 is busy), worker
```

1. Open the app. A deep link to a task while signed out lands on Sign in, then on that task.
2. **Run demo proposal** → watch the progress log → *Ready to review*: show the two files, the **Content preview**, the sources and assumptions; download both; **Mark reviewed** and refresh (stays reviewed; the page says nothing was sent).

6. Say aloud what is simulated: demo email, fixture intelligence, outbox notification, time-compressed overnight story.
